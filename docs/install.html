Installation Guide

Get Kamlux running on your KDE Plasma system

Arch Linux

Method 1: Quick Install (Recommended)

curl -sL https://AtelierMizumi.github.io/kamlux/install-arch.sh | bash

Or download and run manually:

wget https://AtelierMizumi.github.io/kamlux/install-arch.sh
chmod +x install-arch.sh
./install-arch.sh

The installer will:

  • Check dependencies (python3, v4l-utils)
  • Ask for your preferences
  • Install to ~/.local/share/kamlux
  • Create systemd user service

Method 2: Manual Install

# Install dependencies
sudo pacman -S python python-v4l-utils

# Create directories
mkdir -p ~/.local/share/kamlux
mkdir -p ~/.config/kamlux

# Clone repository
git clone https://github.com/AtelierMizumi/kamlux.git
cd kamlux

# Copy files
cp src/kamlux.py ~/.local/share/kamlux/
cp src/config.json ~/.config/kamlux/config.json
chmod +x ~/.local/share/kamlux/kamlux.py

# Create launcher
mkdir -p ~/.local/bin
echo '#!/bin/bash' > ~/.local/bin/kamlux
echo 'python3 "$HOME/.local/share/kamlux/kamlux.py" "$@"' >> ~/.local/bin/kamlux
chmod +x ~/.local/bin/kamlux

# Add to PATH (add to ~/.bashrc or ~/.zshrc)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

# Setup systemd service
mkdir -p ~/.config/systemd/user
cp systemd/kamlux.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now kamlux.service

Configuration

After installation, config is at ~/.config/kamlux/config.json

{
    "device": "/dev/video0",
    "interval": 10,
    "smoothing_alpha": 0.8,
    "curve": [
        [0.0, 100.0],
        [0.31, 80.0],
        [0.5, 40.0],
        [0.8, 20.0],
        [1.0, 5.0]
    ],
    "override_cooldown_minutes": 30
}

Configuration Options

Option Description Default
device Camera device path /dev/video0
interval Seconds between brightness checks 10
smoothing_alpha Response speed (0.1=slow, 1.0=instant) 0.8
curve Maps darkness (0-1) to brightness (0-100%) See above
override_cooldown_minutes Wait time after manual brightness change 30

Usage

Commands

# Run in terminal (for debugging)
kamlux

# Start service
systemctl --user start kamlux

# Stop service
systemctl --user stop kamlux

# Check status
systemctl --user status kamlux

# View logs
journalctl --user -u kamlux -f

Troubleshooting

Brightness not changing?

# Check camera is accessible
v4l2-ctl -d /dev/video0 --get-ctrl=gain

# Check KDE brightness control
qdbus org.kde.Solid.PowerManagement /org/kde/Solid/PowerManagement/Actions/BrightnessControl org.kde.Solid.PowerManagement.Actions.BrightnessControl.brightness

# Run in terminal to see debug output
kamlux

Camera not detected?

# Check available cameras
ls /dev/video*

# Update config with correct device
nano ~/.config/kamlux/config.json

Service won't start?

# Check logs
journalctl --user -u kamlux.service

# Try running manually
python3 ~/.local/share/kamlux/kamlux.py
