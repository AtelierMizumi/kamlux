About Kamlux

Smart automatic brightness for KDE Plasma

What is Kamlux?

Kamlux is an automatic screen brightness adjustment daemon designed specifically for KDE Plasma. It uses your computer's webcam to detect ambient light levels and adjusts your screen brightness accordingly - no external light sensors required.

Unlike traditional solutions that require specialized hardware, Kamlux leverages the auto-exposure feature already built into your webcam to estimate room brightness. When it's dark, your screen dims. When it's bright, your screen brightens. Just like your phone, but for your Linux desktop.

How It Works

1. Camera as Light Sensor

Modern webcams have auto-exposure (AE) that automatically adjusts to lighting conditions. In a dark room, the camera increases gain and exposure time. In bright light, it decreases them. Kamlux reads these values to estimate ambient brightness.

2. Darkness Score Calculation

The script normalizes gain and exposure values to create a "darkness score" between 0 and 1:

darkness = (gain_norm + exp_norm) / 2

Where:

  • gain_norm = normalized gain (0 = min, 1 = max)
  • exp_norm = normalized exposure (0 = min, 1 = max)

3. Brightness Curve Interpolation

The darkness score is mapped to screen brightness using a configurable curve. The default curve:

curve = [
    [0.0, 100.0],   # Full light → 100% brightness
    [0.31, 80.0],   # Normal room → 80% brightness
    [0.5, 40.0],    # Dim room → 40% brightness
    [0.8, 20.0],    # Dark room → 20% brightness
    [1.0, 5.0]      # Very dark → 5% brightness
]

4. Smooth Transitions

To prevent jarring changes, Kamlux uses exponential moving average (EMA):

new_brightness = (alpha * target) + ((1 - alpha) * current)

With alpha=0.8, the brightness adjusts quickly but smoothly.

Why KDE Plasma?

KDE Plasma provides excellent D-Bus interfaces for brightness control through PowerDevil. This makes it the ideal desktop environment for brightness automation because:

  • Native integration - Uses the same APIs as KDE's built-in brightness controls
  • No conflicts - Properly respects KDE's power management
  • Reliable - qdbus commands work consistently
  • Percentage-based - Easy to map to 0-100% scale

While Kamlux is designed for KDE Plasma, the core logic could be adapted for other desktop environments that provide D-Bus or other brightness control APIs.

Technical Details

Dependencies

  • Python 3.10+ - Main runtime
  • numpy - For curve interpolation
  • v4l-utils - For camera access via v4l2-ctl
  • qdbus - For KDE Plasma D-Bus communication

How to Find Your Optimal Curve

  1. Run kamlux in terminal
  2. Note the "Darkness" value in different lighting conditions
  3. Adjust curve points in config.json to match your preferences
